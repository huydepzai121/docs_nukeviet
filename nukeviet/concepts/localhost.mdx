**Web server** (máy chủ web) là máy chủ chuyên phục vụ cho các dịch vụ web (bao gồm dịch vụ chính là lưu trữ web - web hosting). NukeViet được viết để chạy trên các máy chủ web. Để thử nghiệm NukeViet trên máy tính cá nhân (Laptop, PC...) chúng ta cần cài thêm phần mềm máy chủ web cho máy tính của mình. Đây là môi trường hỗ trợ NukeViet cũng như bất kỳ một ứng dụng nào viết bằng PHP như Web, Portal, Forum, Chat, Webmail …

Các phần mềm máy chủ web sẽ giúp máy tính của bạn có khả năng chạy các dịch vụ tương tự các máy chủ web hosting. Web hosting ở chính máy tính của mình được gọi là **localhost**, được truy cập thông qua địa chỉ [http://localhost/](http://localhost/) hoặc [http://127.0.0.1/](http://127.0.0.1/).

Các phần mềm web server là một cách nhanh chóng và đơn giản để chúng ta thiết lập web hosting mà không phải mất công cài từng phần mềm rời rạc như Apache, PHP, MySQL...
