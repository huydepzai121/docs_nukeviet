## Tác dụng

API dùng để thêm/sửa/xóa thông báo đẩy dành cho điều hành nhóm

### Tham số có thể truyền vào:

### Request Parameters

| Tham số | Kiểu dữ liệu | Tính bắt buộc | Mô tả |
|:---|----|:---|:---|
| group_id | int | Bắt buộc | ID của nhóm gửi thông báo đẩy trong CSDL |
| **operation** | string | Bắt buộc | Là một trong các hành động của API: Thêm (add), sửa (edit), xóa (delete) |
| id | int | Bắt buộc nếu **operation** là edit hoặc delete | ID của thông báo đẩy trong CSDL |
| receiver_ids | array | Không bắt buộc | Danh sách ID của thành viên nhóm nhận thông báo. Giá trị rỗng = gửi thông báo cho tất cả |
| **isref** | **string** | **Bắt buộc nếu operation là edit hoặc add** | **Mã ngôn ngữ của message mặc định** |
| **message** | **array** | **Bắt buộc nếu operation là edit hoặc add** | **Nội dung thông báo, có dạng cặp key =\> value, kiểu như: \[ 'en' =\> 'Content', 'vi' =\> 'Nội dung' \] Trong đó phần value của key ngôn ngữ mặc định là bắt buộc. Nó được dùng để thay thế cho message rỗng của các ngôn ngữ khác** |
| link | string | Không bắt buộc, **nếu có thì bắt buộc phải có ở ngôn ngữ mặc định** | Liên kết của thông báo, **có dạng cặp key =\> value, kiểu như: \[ 'en' =\> 'linken', 'vi' =\> 'linkvi' \] Trong đó phần value của key ngôn ngữ mặc định là bắt buộc. Nó được dùng để thay thế cho link rỗng của các ngôn ngữ khác** |
| add_time | string | Bắt buộc nếu **operation** là edit hoặc add | Ngày/Tháng/Năm bắt đầu hiển thị thông báo (định dạng dd/mm/YYYY) |
| add_hour | int | Không bắt buộc | Giờ bắt đầu hiện thị thông báo |
| add_min | int | Không bắt buộc | Phút hiển thị thông báo |
| exp_time | string | Không bắt buộc | Ngày/Tháng/Năm hết hạn hiển thị thông báo (định dạng dd/mm/YYYY) |
| exp_hour | int | Không bắt buộc | Giờ kết thúc thông báo |
| exp_min | int | Không bắt buộc | Phút kết thúc thông báo |
| **Checkhash** (Tạm thời không sử dụng) | **string** | **Bắt buộc** | **Là sha1 của chuỗi được tạo từ http_build_query của các tham số trên sau khi áp dụng ksort** |

### Dữ liệu trả về:

| Thuộc tính | Kiểu dữ liệu | Mô tả |
|----|----|:---|
| status | string | Trạng thái truy vấn: thành công (success) hoặc lỗi (error) |
| code | int | Mã lỗi (0000 – nếu trạng thái success) |
| message | string | Thông báo lỗi (Rỗng nếu trạng thái success) |
