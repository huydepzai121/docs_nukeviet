Để đáp ứng cho chức năng test tự động, kho code NukeViet 5 đã tiến hành thay đổi cấu trúc so với kho code ở NukeViet 4. Cụ thể như sau:

- Toàn bộ các file và thư mục của NukeViet được chuyển vào thư mục src. Như vậy để lấy kho code mới nhất ta chỉ cần lấy các file và thư mục trong `src` để sử dụng.
- Sinh thêm thư mục `tools` để chứa các công cụ dành cho nhà phát triển trong quá trình lập trình.
- Sinh thêm thư mục `tests` để chứa các file phục vụ auto test.
