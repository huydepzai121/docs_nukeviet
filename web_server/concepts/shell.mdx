## Shell là gì?

Shell là một đoạn code chạy trên server giúp người điều khiển nó có thể truy cập (thường là trái phép) các tài nguyên trên server. Shell chủ yếu được viết bằng php, asp - là các ngôn ngữ lập trình được sử dụng nhiều nhất cho các server web.

## Shell có phải virus không?

Shell không phải virus, shell thực chất chỉ là một đoạn code không hơn không kém. Nhưng đoạn code đó thường được các hacker sử dụng như một công cụ để khai thác trái phép các dữ liệu trên server.

## Tại sao Shell nguy hiểm?

Vì nó là công cụ rất mạnh, và một khi được đưa lên host hoặc server, ai cũng có thể sử dụng nó một cách khá dễ dàng.
