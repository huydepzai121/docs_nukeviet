### Chú ý khi sử dụng mảng

Việc dùng key của mảng dạng float sẽ gây ra một số rắc rối và sai dữ liệu. Do đó chỉ nên dùng key của mảng dạng int hoặc string. Ví dụ

``` php
$a = [];
$a['15.5'] = 1; 
$a[15.5] = 2; 
$a[15.0] = 3;

print_r($a);
```

Kết quả chỉ có

``` text
Array
(
    [15.5] => 1
    [15] => 3
)
```

Vì số 15.5 được chuyển thành 15 trong key
