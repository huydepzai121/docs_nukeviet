### Thay đổi khi sử dụng class

Tạo một thuộc tính động cho một class sẽ gây ra lỗi cảnh báo. Ví dụ

``` php
class User
{
    public $name;
}

$user = new User();
$user->last_name = 'Doe'; // Lỗi cảnh báo Deprecated khi thuộc tính last_name chưa được định nghĩa.
```

**Hướng dẫn**

Dùng regex sau để tìm kiếm ra những chỗ dùng như thế `\$(?!this)[a-zA-Z_][a-zA-Z0-9_]*\s*-\s*>[\r\n\s\t]*[a-zA-Z_][a-zA-Z0-9_]*[\r\n\s\t]*\=[\r\n\s\t]*[\$a-zA-Z0-9\'\"]`. Nếu dùng Eclipse giữ Ctrl và di chuột qua các thuộc tính đó, nếu có liên kết là ok. Không có liên kết tức là thuộc tính đó không tồn tại.

**Nên làm**

Khai báo nó trong class trước khi sử dụng.

**Cách khác**

Thêm `#[\AllowDynamicProperties]` vào class đó ví dụ

``` php
#[\AllowDynamicProperties]
class User
```
